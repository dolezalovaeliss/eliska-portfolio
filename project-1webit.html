1. Web IT

A complete website redesign and brand refresh for 1. Web IT s.r.o., a development-first IT company. I drew from the company’s developer DNA, using IT-world visual metaphors: browser dialog boxes repurposed as CTA sections, code-styled accents, terminal-inspired typography.

The updated identity gave the brand a contemporary direction and a clearer voice. Collaboration continues to support the brand’s evolution while keeping it authentic.
