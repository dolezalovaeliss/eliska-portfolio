WebScannerPro

Feature animations for WebScannerPro, a browser extension by Cybertrends. Each loop explains one feature in a few seconds: scam and phishing sites stopped before they load, pop-up ads blocked, trackers counted as they’re blocked, and your IP hidden behind private browsing.

Built from the extension’s own UI in a soft blue palette with a single indigo accent, so every loop reads like the product itself.
